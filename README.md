# Student Grade Calculator 🎓

A beginner-friendly C++ project that calculates a student's total marks, percentage, grade, and pass/fail result.

## ✨ Features

- Takes student name as input
- Takes marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns grade
- Displays pass/fail result

## 🛠️ Technology Used

- C++

## 📚 Concepts Used

- Variables
- Input and Output
- Arithmetic Operators
- If-Else Statements
- Basic Programming Logic

## 🚀 How It Works

The program takes marks of five subjects from the user, calculates the total and percentage, and then displays the student's grade and result.
